# Social Media App Prototype (Figma)

This project is a low-fidelity prototype of a social media application created in Figma.

## Features
- Login screen
- Home feed with posts
- Basic navigation
- Interactive prototype

## Figma Prototype Link
https://www.figma.com/proto/KDxszHLp8QrqlVg8lem2IC/Login?page-id=0%3A1&node-id=1-2&viewport=89%2C42%2C0.88&t=ZFvyxZxT5mvJNYpn-1&scaling=scale-down&content-scaling=fixed&starting-point-node-id=1%3A2

## Description
Users can log in and view posts from other users in a social media feed. The prototype demonstrates basic UI layout and navigation flow.
